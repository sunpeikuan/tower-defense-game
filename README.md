# 领地占领塔防游戏

参考《守卫迷城》的策略型塔防游戏。

## 游戏规则

### 基本目标
- 防守基地，抵挡敌人入侵
- 生命值降为0或敌人全部突破防线时游戏结束
- 完成所有10波敌人进攻即获胜

### 防御塔

1. **弓箭塔** 🏹 (100金币)
   - 伤害: 25
   - 范围: 150
   - 发射速度: 快

2. **魔法塔** ✨ (150金币)
   - 伤害: 40
   - 范围: 120
   - 特效: 溅射伤害(范围60)

3. **减速塔** ❄️ (120金币)
   - 伤害: 10
   - 范围: 140
   - 特效: 减速敌人到50%速度

4. **炮塔** 💣 (200金币)
   - 伤害: 60
   - 范围: 130
   - 特效: 大范围溅射(范围80)

### 资源系统
- **初始金币**: 500
- **敌人金币**: 击杀敌人获得20+波数*5的金币
- **金币用途**: 建造和升级防御塔

### 游戏特色
- 🎮 智能敌人AI和波次管理
- ⚡ 游戏加速功能
- 📊 实时统计面板
- 🎨 现代化UI设计
- 📱 响应式布局

## 如何运行

### 本地运行
1. 克隆仓库
   ```bash
   git clone https://github.com/sunpeikuan/tower-defense-game.git
   cd tower-defense-game
   ```

2. 用浏览器打开 `index.html`
   - 双击 `index.html` 文件
   - 或右键选择 "用浏览器打开"

### 在线游戏
- 使用GitHub Pages访问游戏
- 在浏览器地址栏输入: `https://sunpeikuan.github.io/tower-defense-game/`

## 游戏操作

1. **选择塔类型**: 点击左侧菜单中的防御塔按钮
2. **放置防御塔**: 在画布上点击位置，放置已选择的塔
3. **开始波次**: 点击 "开始波次" 按钮，敌人开始进攻
4. **加速游戏**: 点击 "加速" 按钮，游戏速度变为2倍
5. **清空选择**: 点击 "清空选择" 恢复正常状态

## 游戏提示

- 👨‍💼 在敌人来临前准备好防御塔
- 💡 合理搭配不同类型的塔，发挥最大效能
- 📈 敌人难度随波次递增，需要合理升级
- ⚡ 使用加速功能快速推进游戏

## 技术栈

- HTML5 Canvas 游戏渲染
- Vanilla JavaScript 游戏逻辑
- CSS3 响应式布局
- 无外部依赖
